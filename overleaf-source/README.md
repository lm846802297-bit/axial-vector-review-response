# Overleaf manuscript source archive

本目录是从 Overleaf 导出的论文源码快照，按只读来源归档管理，不是当前回复信的构建目录。

[axial-vector-model-building-v6/](axial-vector-model-building-v6/) 保留 `main-v1.tex`、`main.tex`、参考文献数据库、样式文件、图像资源和原包附带的回复材料。带署名的其他历史主文版本不再放在默认分支。

## 使用边界

1. 编译时将 `axial-vector-model-building-v6/` 作为项目根目录，并明确选择主文文件。
2. 此源码归档的完整干净编译及其与论文基线 PDF 的逐页等价性尚未通过独立验收；两张较大图经过 PDF 重新编码。
3. 默认分支不再提供带署名的 v6 基线 PDF；不要仅凭文件名推断源码与正式稿件完全等价。
4. 根目录正式回复信使用独立的 TeX/BibTeX 构建链；不要将其两份 bibliography 与本源码包的数据库混为一套。
5. 本目录中的历史源码不等于作者当前采用的修订稿。正文修改须与活动源文件、正文同步清单和正式回复信核对。

当前状态见 [`PROJECT_STATUS.md`](../PROJECT_STATUS.md)，导航见 [`仓库分类索引.md`](../仓库分类索引.md)。
