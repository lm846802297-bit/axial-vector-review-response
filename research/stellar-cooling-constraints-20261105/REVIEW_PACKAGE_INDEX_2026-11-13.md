# Axial stellar-cooling collaborator archive index

## Canonical source layout

The collaborator package is built from the canonical research files; it does not keep a second extracted copy of the same files.

- research/stellar-cooling-constraints-20261105/: axial EFT calculation, reconstructed profiles, scan outputs, plotting, tests, and the independent Blinov B.13/B.16 research programme.
- research/stellar-cooling-original-uv-model-20261105/: original single-VEV model mapping and validation.
- research/stellar-cooling-two-vev-20261105/: two-VEV model mapping and validation.
- research/stellar-cooling-eft-literature-20261105/: independent literature-kernel implementation and checks.
- research/stellar-cooling-collaborator-archive-20261113/: collaborator guide, status matrix, figure audit, reviewer checklist, package builder, and dependency list.

The historical directory review_package_extracted/ is retired and removed from the current branch. Its duplicated source copies are not used as canonical inputs.

## Build and download the ZIP

The workflow .github/workflows/build-stellar-cooling-review-archive.yml runs the axial benchmark tests, validates saved outputs, creates a log-log plot-interpolation audit, and builds a de-duplicated ZIP artifact.

Artifact name:

Stellar_Cooling_Research_Archive_2026-11-13

The ZIP is generated by GitHub Actions and is not committed to the repository. The repository stores the source, documentation, checks, and builder only.

## Package contents and de-duplication

The package builder includes all tracked files from the four canonical research roots above, plus relevant stellar-cooling GitHub Actions workflows. It preserves each source subdirectory and records every file in SOURCE_FILE_CATALOG.csv with:

- original repository path;
- packaged path;
- inclusion / alias / external-release status;
- byte count;
- SHA-256;
- Git blob SHA when available;
- a short file description.

Byte-identical files are stored once and all aliases point to the canonical packaged copy. The historical review_package_extracted/ directory is excluded. The five large SFHo-FRDM ZIP payloads are not copied into the collaborator ZIP; they remain in the sfho-frdm-v1.03-data GitHub Release and are listed in the catalog with their manifest checksums. No private Garching raw simulation profile is included.

## Scientific status

This is a reproducible fixed-profile axial-EFT ballistic-cooling benchmark, not a final SN1987A exclusion. The pure-vector Blinov Fig. 7 end-to-end gate remains not passed at the 10 MeV strong-absorption tail. The axial production scan still uses an initial-muon-rest semi-Compton approximation rather than the full moving-muon B.13 thermal kernel. The mode-resolved versus scalar opacity prescription and background / energy-frame assumptions remain open physical gates.
