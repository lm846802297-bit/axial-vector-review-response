# RC-001 — External-W five-point SU(2) weak-index ordering audit

**Workstream:** RC-001-WW-UV-FF-02, Stage B2b (weak-generator ordering)  
**Status:** the six internal-W pair tensors, both possible external-W generator orderings on each matter endpoint, their commutator relation to the three-W tensor, and all scalar-seagull anticommutators have been checked exactly. This fixes weak-index algebra only; it does not determine the full graph phases or close the Slavnov–Taylor identity.

## 1. All-incoming external-index action

Use the four-point weak tensor
\[
T_0{}_{ijkl}=\delta_{ij}\delta_{kl},
\qquad
T_3{}_{ijkl}=\sum_I\sigma^I_{ij}\sigma^I_{kl}.
\]
For the all-incoming amplitude ordering \((\bar L_i,H_j,H^\dagger_k,L_l)\), define the signed external-index actions \(\mathscr T_r^a\) by
\[
\begin{aligned}
(\mathscr T_0^a X)_{ijkl}
&=\sum_m t^a_{mi}X_{mjkl},\\
(\mathscr T_1^a X)_{ijkl}
&=-\sum_m t^a_{jm}X_{imkl},\\
(\mathscr T_2^a X)_{ijkl}
&=\sum_m t^a_{mk}X_{ijml},\\
(\mathscr T_3^a X)_{ijkl}
&=-\sum_m t^a_{lm}X_{ijkm},
\end{aligned}
\qquad t^a=\frac{\sigma^a}{2}.
\]
These signs are the external-index convention used in the existing Stage-A audit. In this convention each signed action satisfies
\[
[\mathscr T_r^a,\mathscr T_r^b]
=-i\epsilon^{abc}\mathscr T_r^c.
\]
The complete sum over the four external slots annihilates both \(T_0\) and \(T_3\).

## 2. Internal-W pair tensors

For a pair of endpoints \(A,B\), the weak tensor generated by the internal W exchange is
\[
\mathcal T_{AB}
=\sum_b\mathscr T_A^b\mathscr T_B^b T_0.
\]
The exact projections are:

| Pair | Endpoint slots \(A,B\) | Internal-W weak tensor |
|---|---|---|
| LD-W-01 | \(\bar L,L\) | \(-T_3/4\) |
| LD-W-02 | \(\bar L,H^\dagger\) | \(+T_3/4\) |
| LD-W-03 | \(\bar L,H\) | \(-3T_0/4\) |
| LD-W-04 | \(L,H^\dagger\) | \(-3T_0/4\) |
| LD-W-05 | \(L,H\) | \(+T_3/4\) |
| LD-W-06 | \(H^\dagger,H\) | \(-T_3/4\) |

The calculation checks all 16 weak-index components for each of the six pairs. This reproduces the Stage-A pair projection, now in the same signed-action notation used for the external-W insertions.

## 3. Matter-line ordering and the three-W commutator tensor

Let
\[
\mathcal G_{AB}^a
=\epsilon^{abc}\mathscr T_A^b\mathscr T_B^c T_0
\]
denote the weak tensor associated with the three-W insertion on the internal gauge line.

There are two possible generator orderings when the external W is inserted on endpoint \(A\):
\[
\mathcal A_{A,\mathrm{out}}^a
=\sum_b\mathscr T_A^a\mathscr T_A^b\mathscr T_B^bT_0,
\qquad
\mathcal A_{A,\mathrm{in}}^a
=\sum_b\mathscr T_A^b\mathscr T_A^a\mathscr T_B^bT_0.
\]
Using the signed-action commutator,
\[
\boxed{
\mathcal A_{A,\mathrm{out}}^a
-\mathcal A_{A,\mathrm{in}}^a
=+i\,\mathcal G_{AB}^a.
}
\]
For an external W inserted on endpoint \(B\),
\[
\boxed{
\mathcal A_{B,\mathrm{out}}^a
-\mathcal A_{B,\mathrm{in}}^a
=-i\,\mathcal G_{AB}^a.
}
\]
Thus the noncommuting part of the two matter-line orderings is exactly the same weak tensor as the internal three-W graph, with the relative endpoint signs fixed by the all-incoming convention.

This is an algebraic group identity, not yet a cancellation of complete Feynman amplitudes. The Lorentz numerators, propagator factors, vertex phases, and the orientation of the internal W line must still be restored before the relative diagram sign is declared.

## 4. Scalar-seagull weak tensor

For a scalar endpoint \(A\), the two-gauge seagull contains the anticommutator of the external and internal generators. Since
\[
\{t^a,t^b\}=\frac12\delta^{ab}\mathbf1,
\]
its weak tensor obeys
\[
\boxed{
\sum_b
\{\mathscr T_A^a,\mathscr T_A^b\}
\mathscr T_B^bT_0
=\frac12\mathscr T_B^aT_0.
}
\]
The same relation holds with \(A\) and \(B\) exchanged. The exact audit checks this identity for every scalar endpoint in the six-pair census, for all three external W generators and all 16 external weak-index components.

This shows that the scalar seagull contributes a definite endpoint generator. It cannot be omitted, and it must be combined with the scalar-line and internal-W contributions using the same phase convention.
