## 2. 总体审查结论

Major Point 1 的总体回答应围绕以下论证链组织：

1. **UV 结构：** 原论文单 VEV \(S+\mathrm{VLL}\) 模型中，径向标量 \(s\) 是物理自由度；\(m_s\)、\(y_{s\mu\mu}\)、\(y_{s\tau\tau}\) 与 \(v_s,\lambda_S\) 的关系由模型确定。
2. **理论质量范围：** 微扰性给出点依赖的 \(m_s\) 上界；Fig. 2 的 scalar-suppressed benchmark 具有明确适用条件。
3. **低质量约束：** Table II 汇总不同来源、不同观测量和不同归一化下的标量约束；它不是一条合并的 exclusion band。
4. **间接约束的 UV 映射：** 第五力通过圈图诱导的质子耦合产生；Fiorillo 的 muon-only 曲线不能直接当作 \(y_{s\mu\mu}\) 或 \(g_X\) 限制。原论文 UV 模型的低动量 \(s\gamma\gamma\) 振幅包含 μ、τ 两个轻子圈，二者相加。
5. **额外衰变道与参数转换：** \(s\to A'A'\) 开放时改变总宽度、可见分支比和末态；对直接约束同一 \(y_{s\mu\mu}\) 归一化的来源结果，才使用条件性的 \(g_X\) 转换。
6. **其他标量现象学：** 对撞机搜索、\((g-2)_\mu\) 和 Higgs portal 分别在相应子问题中讨论。

原文的主要问题不是科学内容缺失，而是 Table II 前后的说明重复表格已有信息；第五力的限制性质在相邻段落重复解释；\(s\to A'A'\) 的说明采用了不够直接的防御性措辞；结尾又重复总结前文。另有一处表格内部不一致：第五力行把 \(30\,\mathrm{meV}\) 放在“Scalar-mass range”列，容易被理解为实验质量覆盖的硬上限，但正文实际将其定义为第五力曲线与天体物理限制的交叉尺度。

## 3. 本次实际修改

### 3.1 UV 关系与微扰性

- 将开头改为直接说明径向模式 \(s\) 是 UV 模型的物理自由度。
- 明确区分：固定 \(v_s\) 时 \(m_s\) 由 \(\lambda_S\) 控制，而领先阶带电轻子 Yukawa 耦合由 \(v_s\) 决定。
- 压缩树级质量关系后的解释，保留 heavy-VLL、negligible-portal-mixing benchmark、\(v_s=m_{A'}/(2g_X)\) 和 \(\lambda_S\) 的物理关系。
- 保留 \(\lambda_S^{\max}=4\pi\)、\(m_s\gtrsim10\,\mathrm{GeV}\) 的 Fig. 2 scalar-suppressed benchmark 及其点依赖上界。

### 3.2 Table II 与来源解释

- 删除 Table II 前重复写出的 \(y_{s\mu\mu}=2g_Xm_\mu/m_{A'}\) 公式；该关系已经在前面的 UV matching 公式中给出，表格引导句改为引用前述关系。
- 保留 Liu–Tang 标量双星脉冲星结果的 Yukawa 归一化、最佳灵敏度点与质量区间的区别；明确 Dror et al. 的矢量媒介结果不作为标量 Yukawa 限制，并补齐对应引用。
- **纠正第五力表格质量列：** 将 \(m_s\lesssim30\,\mathrm{meV}\) 改为“mass-dependent”。\(30\,\mathrm{meV}\) 只在适用性列和正文中作为近似交叉尺度出现，不再被写成质量覆盖端点。
- 将原约 266 词的表后解释压缩为一个较短段落。仍保留以下独立信息：
  - Fiorillo v2 中子星冷却的质量依赖覆盖至约 \(100\,\mathrm{keV}\)，而 Table 1 的 \(7.4\times10^{-14}\) 只对应 \(m_s\lesssim1\,\mathrm{keV}\)；
  - SN 1987A 中微子能量损失采用 Caputo Fig. 2 的 cold-SFHo free-streaming 曲线，不能把 Fiorillo Table 1 的质量标签误当作该曲线的质量端点；
  - SN 1987A 单次伽马射线 fluence 与 diffuse-supernova gamma-ray background 是不同观测量，仍分别列出；
  - 超新星结果保留 source-specific free-streaming benchmark 的限定；
  - Caputo 源归一化 \(g_{\phi\mu}^{\rm source}\)、约 \(10\,\mathrm{MeV}\) 的来源适用范围，以及 photon-mediated 结果仍是 muon-only source benchmark、不是完整 \((\mu,\tau)\)-matched UV recast 的限定。

### 3.3 第五力与 μ、τ UV matching

- 保留第五力的核心物理机制和公式
  \[
  g_{\phi p}^{(\mu)}=\frac{\alpha^2}{4}g_{\phi\mu},
  \]
  并明确它是在低动量极限及 Fiorillo 的耦合归一化下使用。
- 保留普通物质第五力实验限制圈图诱导的质子耦合，而不是树级标量–缪子 Yukawa 顶点这一关键区别。
- 保留 \(30\,\mathrm{meV}\) 是交叉尺度、不是实验灵敏度硬端点的说明。
- 将 UV 双轻子圈推导压缩，但完整保留
  \[
  \frac{y_{s\mu\mu}}{m_\mu}
  =\frac{y_{s\tau\tau}}{m_\tau}
  =\frac1{v_s},
  \]
  以及 \(s\gamma\gamma\) 形状因子中的 μ、τ 求和。
- 保留低动量下两种轻子圈同号相加、振幅正比于 \(2/v_s\) 的结论；说明 \(U(1)_{L_\mu-L_\tau}\) 的相反规范荷不会抵消依赖 \(Q_\ell^2\) 的电磁振幅。
- 删除紧邻段落中重复出现的“不是直接 \(y_{s\mu\mu}\) 限制”说明，只在物理机制和 UV matching 处各自保留其必要论证功能。

### 3.4 \(s\to A'A'\)、条件性 \(g_X\) 转换与段落过渡

- 将 “not invalidated wholesale” 的防御性表达改为直接说明：当 \(m_s>2m_{A'}\) 时，\(s\to A'A'\) 进入总宽度，并影响可见分支比、寿命和末态拓扑；在对这些量敏感的观测量上进行 UV-specific reinterpretation 时必须纳入该道。
- 保留直接标量–缪子限制到 \(g_X\) 的条件性转换：
  \[
  g_X\lesssim
  \frac{y_{s\mu\mu}^{\rm lim}(m_s)m_{A'}}{2m_\mu}.
  \]
  同时保留该转换依赖来源质量范围和相同 Yukawa 归一化、不是普适 \(g_X\) 上限的限定。
- 删除该转换段落中再次解释第五力为何不能直接代入的重复句；其物理原因已在前面的第五力与 UV matching 段落说明。
- 将“Table II 是 source-anchored summary、不是 combined exclusion map”的重复总结改成通往对撞机搜索的简短过渡。
- 压缩总体 Reply 结尾，只保留 UV 标量约束、Fig. 2 scalar-suppressed benchmark 与 Major Point 1.3 portal/mixing 之间的关系。
