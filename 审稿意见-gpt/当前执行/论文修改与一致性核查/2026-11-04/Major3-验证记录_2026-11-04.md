符号恒等式的复核核心代码（不依赖数值拟合）：

```python
import sympy as s
A, B, C, D, E, F, d1, d2, d3 = s.symbols(
    "A B C D E F d1 d2 d3", nonzero=True
)
M = s.Matrix([[A, B, C], [B, D, E], [C, E, F]])
d = s.diag(d1, d2, d3)
R = -d.T * M.inv() * d
assert (-d * R.inv() * d.T - M).applyfunc(s.simplify) == s.zeros(3)
RS = s.Matrix([[A, 0, 0], [0, D, E], [0, E, F]])
MS = -d * RS.inv() * d.T
assert MS[0, 1] == MS[0, 2] == 0
```
