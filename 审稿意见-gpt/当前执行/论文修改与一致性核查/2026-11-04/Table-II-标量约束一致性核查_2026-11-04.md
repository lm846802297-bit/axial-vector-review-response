## 1. 核心区分

Table II 汇总文献在各自有效标量–μ子耦合基准下给出的 source-reported limits/sensitivities。UV 模型则通过
\[
y_{s\mu\mu}=\frac{m_\mu}{v_s}
=\frac{2g_Xm_\mu}{m_{A'}}
\]
在满足匹配条件时将有效耦合映射到 \((m_{A'},g_X)\)。

二者不能混为一谈。Table II 不是完整 UV 参数空间排除图；文献中的 muonphilic benchmark 也不能自动视为完整 μ、τ UV 模型的 loop-mediated result。

特别地，UV 中存在 \(s\to A'A'\) 不意味着所有低质量标量 source constraints 自动失效。该道仅在 \(m_s>2m_{A'}\) 时打开；只有对标量寿命、可见分支比、传播或能量沉积敏感的具体观测，才需要在相应运动学区域纳入该衰变。不能将这一点扩大成对所有 Table II 条目的统一否定。

## 4. 来源与物理含义

### 4.1 Binary-pulsar periastron advance

Liu and Tang, *Probing a muonic force with the periastron advance in binary pulsar systems*, Phys. Rev. D 112, 055021 (2025), arXiv:2501.10927.

- 相互作用：\(\mathcal L\supset-g_{\phi\mu}\phi\bar\mu\mu\)（按文献的耦合归一化）。
- 质量敏感区间：约 \(10^{-17}\)–\(2\times10^{-15}\) eV。
- 最佳敏感点：\(m_\phi\simeq4\times10^{-16}\) eV，耦合达到 \(O(10^{-21})\)。
- 置信水平：95% CL。
- 该 best-sensitivity value 不能当成全区间平坦上限。
- Dror et al. 的 \(L_\mu-L_\tau\) vector-mediator constraint 不是这个 scalar Yukawa bound 的来源。

### 4.2 Fifth-force tests

Fiorillo et al., arXiv:2605.24094v2.

- muon-only source benchmark 的 loop-induced proton coupling：
  \[
  g_{\phi p}^{(\mu)}=\frac{\alpha^2}{4}g_{\phi\mu}.
  \]
- 第五力结果是质量依赖的 loop-level curve。
- 文献指出该第五力约束在 \(m_\phi\lesssim30\) meV 时强于其天体物理约束。
- 因为普通物质中几乎没有 muon，不能把实验直接写成一个 tree-level scalar–muon Yukawa limit。
- 本次不声称完成完整 UV proton recast。

### 4.3 Neutron-star cooling

Fiorillo et al. v2 的正文指出，中子星冷却对标量的质量依赖灵敏度可延伸至约 \(100\) keV；摘要给出的量级为 \(g_{X\mu}\lesssim10^{-13}\)。

Table I 的标题明确写明其数值针对 \(m_X\lesssim1\) keV。标量列中的 neutron-star cooling 数值为
\[
g_{\phi\mu}\lesssim7.4\times10^{-14}.
\]

所以必须把：
- 约 \(100\) keV 的质量依赖 reach；
- \(m_s\lesssim1\) keV 时 Table I 的 \(7.4\times10^{-14}\)；
分开陈述，不能把 Table I 数值水平外推到整段质量区间。

### 4.4 SN 1987A cooling

同一 Table I 给出 scalar column
\[
g_{\phi\mu}\lesssim4.2\times10^{-9},
\]
并注明是 conservative cold-SN model。Table I 的数值质量基准为 \(m_X\lesssim1\) keV。

该结果应解释为 free-streaming cooling criterion，而不是完整的 trapping、爆炸能量或所有 SN transport exclusions。

### 4.5 Diffuse supernova gamma-ray background

Caputo, Raffelt and Vitagliano, *Muonic Boson Limits: Supernova Redux*, Phys. Rev. D 105, 035022 (2022), arXiv:2109.03244.

- 该文明确研究 muon-philic scalars，不是只研究 ALPs。
- muon triangle loop 诱导 \(s\gamma\gamma\) coupling。
- 对自由逃逸的标量，弥散 cosmic gamma-ray 背景能量预算约要求 \(E_\gamma\lesssim10^{-4}E_{\rm SN}\)。
- 对 \(m_s\gtrsim100\) keV，来源给出 \(g_\phi\lesssim0.4\times10^{-10}=4.0\times10^{-11}\) 的 muonphilic scalar benchmark。
- 这与 SN 1987A cooling threshold 是不同的 observable，不能合并。
- Balazs et al. 的 ALP-only cosmological analysis 不用作 muonic scalar Yukawa 直接限制。

## 5. μ、τ 双轻子圈与 UV matching

本模型径向标量耦合为
\[
y_{s\mu\mu}=\frac{m_\mu}{v_s},\qquad
y_{s\tau\tau}=\frac{m_\tau}{v_s}.
\]
所以
\[
\frac{y_{s\mu\mu}}{m_\mu}
=\frac{y_{s\tau\tau}}{m_\tau}
=\frac1{v_s}.
\]

低动量下的 scalar–photon form factor 结构为
\[
g_{s\gamma\gamma}^{\rm UV}(q^2)\propto
\sum_{\ell=\mu,\tau}Q_\ell^2
\frac{y_{s\ell\ell}}{m_\ell}
F_{1/2}\!\left(\frac{q^2}{4m_\ell^2}\right).
\]

在 \(q^2\ll4m_\mu^2\) 时，μ、τ 两种轻子圈均处于低能极限，贡献同号叠加；不能因 \(U(1)_{L_\mu-L_\tau}\) 规范荷相反而将标量电磁圈抵消。

因此：
- 二者的树级 \(s\bar\ell\ell\) 关系应写入正文；
- photon-mediated 和 fifth-force source results 需先进行 μ、τ 双轻子匹配；
- Fiorillo 的 \(g_{\phi p}^{(\mu)}\) 只能标为 muon-only source benchmark；
- 本次不声称已完成 UV-specific two-photon/proton recast。

## 6. UV 参数映射与 \(s\to A'A'\)

单个破缺 VEV 的模型关系为
\[
m_{A'}=2g_Xv_s,\qquad
y_{s\mu\mu}=\frac{m_\mu}{v_s}
=\frac{2g_Xm_\mu}{m_{A'}}.
\]

因此，对已一致表达为相同有效 \(y_{s\mu\mu}\) 归一化的 source limit，
\[
g_X\lesssim y_{s\mu\mu}^{\rm lim}
\frac{m_{A'}}{2m_\mu}.
\]

但第五力和 photon-mediated limits 需要先完成 μ、τ 两圈 matching，不能把 muon-only source curve 原样变成 UV \(g_X\) bound。

UV 中 \(s\to A'A'\) 只在
\[
m_s>2m_{A'}
\]
时运动学开放。它对标量寿命、可见分支比或能量沉积敏感的观测需要在该区域纳入；它不意味着所有 source-reported low-mass \(y_{s\mu\mu}\) constraints 自动失效。
