# 研究决策与不可回退事项（动态登记表）

**文档性质：可持续修改的研究决策记录（living decision register）**  
**创建/核对日期：** 2026-11-04

> **本文件不是不可更改的规则书。** 文件名中的“不可回退”表示旧决策不能在没有说明的情况下被悄悄恢复为当前立场，不表示作者永远不能改变观点。作者最新明确指示、最新确认的研究判断或正式批准的新方案，始终可以修改、撤销或替代任何条目。

## 1. 决策优先级

发生冲突时，按以下顺序处理：

1. 作者最新明确表达并确认的观点/指示。
2. 作者后来明确批准的研究方案或决策修订。
3. 本文件中最新的“当前采用”或“条件性采用”条目。
4. 已归档会议总结和会议文字稿。
5. 更早的工作稿、技术参考旧建议、历史 PR 描述和旧聊天结论。

本文件不能覆盖作者的新决定。作者明确改变观点时，应更新条目，并保留旧记录为“已被替代”或“已撤销”，而不是继续执行旧方案。

## 2. 条目状态与修改规则

| 状态 | 含义 |
|---|---|
| 当前采用 | 当前工作按此方向执行；作者可随时重新审议 |
| 条件性采用 | 仅在条目写明的 benchmark、边界条件或近似范围内成立 |
| 待确认 | 有候选观点，但尚未获得作者明确确认或证据不足 |
| 待物理核验 | 属于待检验的物理判断，不能当作已证实结果 |
| 已被替代 | 历史上曾采用，后来被新决定取代；仅用于追溯 |
| 已撤销 | 作者明确取消该决策；保留记录但不再执行 |

- 作者明确提出新观点时，识别它影响哪些条目并更新“当前立场”。
- 新观点与旧条目冲突时，将旧条目标记为“已被替代”或“已撤销”，新增变更记录；不得删除历史依据。
- 作者提出问题、探索可能性或要求比较方案时，不自动视为改变既有决策；必要时标记为“待确认”。
- 物理证据变化时，即使研究目标未变，也应把受影响条目标记为“待物理核验”。
- 不得把研究策略选择伪装成物理定理，也不得把物理上不允许误写成作者不允许研究。
- 每次更新记录日期、变更内容、原因和来源；重要变更同步更新根目录 PROJECT_STATUS.md。
- 本文件中的数值和 benchmark 仅在其适用条件下使用；模型、重整化条件、场归一化或参数基准改变时必须重新核验。

### DEC-05 — Higgs portal 小混合是条件性 matching benchmark，不是对称性结论
- **状态：** 条件性采用
- **最后确认：** 2026-10-27；PR #34 于 2026-11-04 统一 Major 1.3 与 Minor 5
- **当前立场：** (H†H)(S†S) 是规范允许的 portal。小 portal/negligible mixing 是指定匹配尺度和重整化约定下的 benchmark，不是规范对称性强制，也不代表所有标量质量范围的混合都可忽略。
- **必要限定：** m_s≈m_h 的窄近简并区域不包含在小混合近似适用范围内；Higgs-factory 的 e⁺e⁻→Zs 与 h→ss 由不同耦合控制。
- **来源：** [Higgs portal 专题推导](../../higgs_portal_mixing_merged_guide-gemini.md)、当前回复信 Major 1.3/Minor 5、PR #34。
- **重新审议：** 匹配方案、UV portal 边界、RGE、近简并处理或作者的 benchmark 选择改变。

### DEC-07 — 动能混合的匹配边界与物理混合必须区分
