## 二、贯穿全会的四条处理原则（这套口径是会议真正的"观点"）

### 原则 2：文献已系统做过的，不重复做，只补引用
S 与希格斯的耦合（scalar portal）被判定为"非常常见的模型、做的人太多"（01:[05:08]、01:[12:16]）。处理办法：在 "Sum Negligible Higgs Portal Mixing" 附近补一段 + 补若干文献，然后声明本文不再重复。同理适用于：S 在对撞机上的搜寻、B 工厂限制、kinetic mixing 的量级估计（直接引 reference 5 的公式 5，02:[29:16]）。

### 原则 3（本会唯一实质分歧）：全用 argue 会显得敷衍，关键处要给算出来的东西

- **折中结论**：树图层次假设 S–H 无耦合，**算一圈图诱导的 SH mixing**（h–s 通过 W/top 或 μμ、ττ 走一圈），给出混合角量级，论证其被 θ 压低后整体很小、对本文结论无影响（01:[14:22]、[25:52]–[26:56]）。这条是全会最可复用的方法论判断。

## 三、逐条审稿意见与处理结论

> 说明：会上并没有按 review 的条目编号顺序念，同一问题常在上下文中重复出现（会上多次吐槽"上面提一遍、下面又提一下，这不就是 AI 的典型"）。以下按**问题族**归并，共 13 组。

### 意见族 A：标量 S 不能忽略 / 为何不把 S 与 A′ 混合起来讨论（01:[00:00]–[06:09]）
**审稿人要什么**：S 不能从动力学上直接"退掉"，应讨论 S 的唯象学（对撞机可见性），并说明为何不与 A′ 一起讨论限制。
**会上判断**：这不是"能不能算"，而是"要不要在本文展开"。三条不展开的理由：
1. 先**承认** S 必须在 UV 模型里存在（它负责给出质量与混合），不能否认；
2. 本文**已经系统讨论**了 S 的限制：轻质量区间来自天文学（恒星、白矮星等）一批限制，文中关注十几 GeV 以上，对撞机与 g-2 的限制也都给了（回应者确认"三个地方都有讨论"）；
3. S 的对撞机搜寻**已有大量文献**系统研究，只需补列，不必重述。
**物理支撑**：在对撞机上研究 S "有哪个过程？"——核心是 **S 不直接与 μ 耦合**，要产生 S 必须先生成 μ，因此 ILC 上只能走 μμ→S，独立信号本就受限，**唯一现实选项是未来的 Muon Collider**（01:[02:02]、[13:18]）。重质量区间当时未细算，只给了 y_Sνν 的限制（S 无法树图直接产生，只能靠末态辐射一类过程）。
**结论**：不改结构。回复信先重述正文已讨论（轻质量天文学 + GeV 级对撞机 + g-2），再声明本文主旨是 **A′ 的唯象学**（S 的唯象学"就是一个 scalar，比较 trivial"），并补文献。

### 意见族 B：M_S 的限制是否与 m_A′、g_X 有关（01:[07:11]–[10:14]）
**审稿人误解**：把 M_S 的限制当作与 A′、g_X 挂钩（"perhaps the authors imagined a range of m_A′ below some benchmark mass…"）。
**会上澄清（关键物理结论）**：
- 本质是 **M_S 与 λ、v_S（以及 y_Sνν）的关系，与 A′ 和 g_X 一点关系都没有**；
- 模型里确实有 m_A′ = g_X·v_S，但 v_S 可以取很大、g_X 可以取很小，故不构成额外限制；y_Sνν 也可取任意小；
- 由标量势得 **M_S < √(4λ)·v_S**（另一处口述为 √(8λ)·v_S，系数需核正文式 34）；另有 g_X、λ_S ≲ √(4π) 的微扰上限；
- 因此**模型内唯一的限制就是 m_A′ 与 M_S 都不能大于 v_S**，二者谁大谁小无所谓（01:[21:37] 复述："这就是唯一的限制了，从模型的角度来看就没有别的限制了"）。
**结论**：把公式列出、把 m_A′ = g_X v_S 代进去，说明限制的是 M_S–λ–v_S 关系；**并把 Table 2 整表复制进回复信**（不让审稿人回原文找）。

### 意见族 C：非 VBF 限制 / 圈图诱导的 S–g_X 耦合，要求给出 loop 公式（01:[11:15]–[17:32]）
**审稿人要什么**：除星体限制外，loop diagram 会诱导非 VBF 限制，应给出表达式；并追问 M_S → m_h 时的 resonance 与 S–H mixing 后果。
**会上判断**：原本有意不讨论 S 与 g_X 的限制，但圈图确实能导出，回避不了。
**两条候选路线**：① 把 loop 项与树图项合起来、论证相互抵消（"直接让它们合起来是 0"）；② 承认 M_S 区间未细算（只取了一个较大的值），逐条回应，再以"文献已系统研究 S–希格斯"收尾。
**最终倾向（见原则 3）**：给出一圈 SH mixing 的量级 —— "S 与 μ 的顶点 × S–希格斯耦合顶点 × θ 角，两个乘起来整体很小"，据此论证可忽略。

### 意见族 D：θ_hS = m_hS²/(m_h² − m_S²) 中的 m_hS² 必须由圈图算出（01:[24:01]–[26:56]）
**会上判断**：AI 只写了公式、没算 m_hS²，属于偷懒（"它没有算，它偷懒了"）。
**指定算法**：h 与 s 之间通过 **W 玻色子或 top 夸克**走一圈（也可先试 μμ、ττ），得出**一圈图的混合角**；本质上就是**希格斯的自能修正**，"应该不是特别难算""场论课都会布置的习题"（两条费米子线的圈）。
**顾虑**：**"要算一算，还是得算出来的，不能完全估计"**（01:[17:32]）；可先查文献（"两个 scalar 中间走一个费米子，不是什么复杂问题，肯定有人算过"）；此前让 AI 算过"算得很差"，怀疑是提示给错；自己手上暂时算不出来，也可用近似或别的办法。

### 意见族 E：Figure 2 参数空间（m_A′–g_X）范围缺乏物理动机（01:[27:57]–[32:07]）
**会上承认**：范围当时确实是按"实验大概做到多少"定的（01:[29:00]），所以"这个不太好搞"，需要正面给理由。
**回复的三个理由（分两端）**：
- **往大质量方向**：① g_X 不能太大（微扰性上限）；② 质量太重，现有实验装置无法 probe。故取 **MeV–100 GeV** 的特征区间。
- **往小质量方向**：低能区**白矮星限制最强**（可无限往低能延伸），且低能时 **g-2 已是最强限制**，再往下画没有意义。
- 口径：先承认区间"可以扩大也可以缩小"，再解释为何只展示这一段（01:[31:07]）。
**顾虑（会上主动提出）**：担心审稿人继续追问天文学限制。天文限制主要来自 **Supernova 与中子星**（μ→μS、μμ→A′、neutrino→A′ 一类过程），但"限制不是特别强"；关键判据是**只有当 A′ 或 S 能逃出星体时限制才成立**，逃不出则无约束（01:[32:07]）。

### 意见族 F：能否同时给出中微子质量矩阵与 PMNS 矩阵（意见 3.1，"Weinberg operator for each generation"）（02:[00:00]–[14:42]）
**审稿人意见**：标准模型只定义左手中微子（中微子即其反粒子，Majorana），质量由温伯格算符产生；本模型能写出哪些温伯格算符？且作者的 Yukawa 质量矩阵与中微子质量矩阵"must be aligned"，因此非平凡矩阵 "doesn't appear to be possible"。
**会上结论（本会最明确的一条"做不到"）**：
- 把 S 计入后用温伯格算符**可以**写出 ν 质量矩阵，但受 U(1)′（L_μ−L_τ 型新对称）限制**只能出现 μ、τ 与 μτ 混合三项**；含 e 的 ee/eμ/eτ 写不出来——"写不出五项，只有这三项"；
- 结果矩阵 M_ee = 0 等，好处是能自然解释 θ23 偏大（近 45°；但具体转角会上没算准，一度说"感觉像 90 多"，随即搁置并提到涉及场的重定义[??]）；
- 要 e 的混合或完整 PMNS，需额外 scalar 或 sterile neutrino；要 UV complete 得给右手中微子派 charge，需要"一堆各种各样的 charge"；
- 高阶项：有 S 时可写 S²/Λ²·LHLH 之类 **dimension-6**（温伯格算符是 dimension-5），"但也不是 UV complete"；
- 关于审稿人说的 "Yukawa matrix"，方两次表示不理解——"我们哪有什么 Yukawa matrix？"，认为实质仍是"给不出 PMNS"；
- 关于"6×6 对角化到 3×3"：引入右手中微子才需 6×6，而审稿人明确不希望引入右手；用 Majorana、温伯格算符里 L 取 L^C 即可，**无需右手**。
**回复策略**：① 承认"能给的就是 μ–τ 结构，完整 PMNS 给不出"，按审稿人思路把能写的温伯格算符写出来；② 正文加一句"ν 振荡质量可由温伯格算符部分给出，但 PMNS 不行"；③ 强调本文本就不打算解释 PMNS——方自评这写法"有点耍赖，因为我们本来就不解决 neutrino mass 问题"，但判断审稿人并未强制要求。

### 意见族 G：是否引入右手中微子 / 有没有更简单的模型 / 该引用什么文献（02:[14:42]–[25:00]）
**审稿人意见**：若第一个问题不好处理，应考虑引入右手中微子；总评是"作者没有能把它纳入的简单模型，若有简单办法应当讲一讲，若不是很简单则应引用"。
**会上的参数论证（回复信的核心弹药）**：
- 引入右手则所需耦合会被 charge 禁掉；方回溯设计初衷——本想引入**两个 scalar**（一个较重，另一个希望 charge 为 2，后当场改口"U(1)′ 等于 1 还是 2？别紧张"，最终口径未定）；
- 最小形式下共 **8 个参数**（1…8），而 PMNS 需要 3 个轻中微子质量 + 3 个右手质量 + 3 个混合角（θ12、θ13、θ23）= **9 个量**，即"8 个参数换 9 个东西"，**参数不够用**；
- 6×6 结构里一侧只能放 3 项、另一侧 2 项；即便取对角或塞入 S（charge 1 或 2，只能取一个）仍不够，必须引新 scalar 填参数；
- 要 UV complete 且加第二、三代多重中微子，就得 vector-like fermion，混合被 charge 禁掉——"确实不够用，但无所谓"；
- 成本结论：**至少加 1 个新 scalar + 三代右手中微子 + 3 个多重中微子 = 加 4 个粒子，连同现有 3 个达 7 个粒子**，模型失控。
**结论**：不引入右手、不补模型；reply 写明"模型自身没办法"并给出上面的成本论证，自评"足够有诚意了"。文献方面："先找，找不到就把这些理由 copy 进 reply"。
**会上判断**：这条是审稿人**用 AI 读出来的**（"AI 会觉得这个东西很重要"）；并吐槽审稿人末句"这个东西没有用、AI……"[??]。

### 意见族 I：UV 模型只实现部分耦合 / vector 与 chiral 限制谁更强（02:[29:58]–[32:45]）
**审稿人意见**：作者给出只实现部分耦合的 UV 模型；应评论"小 vector-like 耦合"可能带来的限制；并指出 "bounds are sensitive to the chiral structure"。
