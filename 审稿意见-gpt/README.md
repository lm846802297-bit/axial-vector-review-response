# 审稿意见与论文修订资料索引

本目录保存审稿意见分析、内部执行记录、研究决策、写作规则、会议材料和研究者阅读资料；它不是正式回复信本身。

## 阅读优先级

1. [项目决策与不可回退事项](项目规范/研究决策与不可回退事项.md)：模型边界、参数选择和作者决策。
2. 根目录 [`PROJECT_STATUS.md`](../PROJECT_STATUS.md)：当前任务状态的唯一实时入口。
3. [v5.7 物理校核与专题连续阅读版](审稿意见分析v5.7-物理校核与专题连续阅读版.md)：综合技术参考。
4. [当前执行目录](当前执行/README.md)：当前修订、任务映射和证据接口。
5. [审稿回复写作原则](写作规范/审稿回复写作原则.md)：正式回复信与内部清单的分离规则。
6. [原始审稿材料](原始审稿材料/README.md)：PDF 变体及可检索文本转录。
