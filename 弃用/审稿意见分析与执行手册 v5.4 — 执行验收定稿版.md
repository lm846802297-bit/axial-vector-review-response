# DW13678 审稿意见分析与执行手册

**版本：v5.4｜执行与验收定稿审校版｜2026-10-19**

> **本文件的用途：** 将审稿意见转为可逐项执行、逐项验收的工作计划。本文件不进行物理推导或数值计算，也不将任务列入视为完成。**这是后续研究工作的执行依据，而不是研究结果报告。**
>
> **当前状态依据：** `审稿意见分析-gpt-v4.1-公式复核与PMNS方案建议-统一更新版-20261019.md`。
>
> **不可变依据：** `axial_vector_model_building-v6.pdf`（最终投稿稿）与 `dw13678_report_1_a.pdf`（原始审稿报告）。不得修改原件。审稿人实际收到的稿件版本若无法从投稿记录确认，应明确登记为“无法确认”，不得猜测。

## 0. 使用规则

### 0.1 这份手册管什么

- 任务拆分、依赖顺序、工作交付物、验收标准和最终审稿意见覆盖检查。
- 物理推导、数值计算、实验文献核查由相应工作包执行；本手册不预先宣布其结果。
- 审稿意见的原始编号始终保留：Major 1–4、Minor 1–6、Recommendation。任何工作项都不能替代原始意见编号。
- 逐条覆盖矩阵采用 38 个语义单元的统计口径：开场与优点评价 5 项、Major 1 计 7 项、Major 2 计 3 项、Major 3 计 4 项、Major 4 计 5 项、Minor 计 13 项、Recommendation 计 1 项。条件性完整性筛查另列，不计入这 38 项。

### 0.2 统一状态

| 状态 | 含义 | 允许的使用方式 |
|---|---|---|
| 未开始 | 尚无实质操作记录 | 只可写计划，不可写成已完成 |
| 进行中 | 已开始，交付物不完整 | 只能报告阶段进度 |
| 待独立复核 | 有草稿结果，但尚未独立检查 | 不可作为最终 rebuttal 的确定结论 |
| 待作者决策 | 技术路线或论文范围需要作者选择 | 不得自行替作者决定 |
| 条件性任务 | 仅在某个候选模型或某个物理通道成立时执行 | 先确认触发条件，再决定执行或关闭 |
| 已完成（验收通过） | 操作、交付物、复核和验收条件全部满足 | 可进入正文和回复信 |
| 阻塞 | 缺少输入、定义、数据或决定 | 记录阻塞原因及解除条件 |
| 不适用（有依据） | 已检查并证明任务不适用 | 必须保存判断依据，不能只写“不相关” |

### 0.3 统一优先级

- **P0：** 影响模型自洽性、核心结论或审稿人明确指出的关键问题。未完成时不得提交最终回复。
- **P1：** 影响参数可行域、实验约束完备性、关键 benchmark 或重要 Minor 回应。
- **P2：** 文字、结构、未来对撞机部分的定位和其他可在核心结论稳定后处理的工作。
- **条件性：** 不等于低优先级；表示只有在选定模型路线或确认物理通道存在后才触发。

### 0.4 来源优先级

1. 原始审稿报告：决定审稿人实际提出了什么。
2. 最终投稿稿 v6：决定原稿实际写了什么。
3. v4.1 主工作文档：记录当前核对状态和未决事项。
4. 专项分析文件：提供推导和候选路线，需检查假设、版本和复核状态。
5. 执行手册：组织工作，不作为独立物理证据。

若文件之间冲突，登记冲突并追到原始依据，不通过“多数文件这么写”来裁定。

### 0.5 每个任务的完成标准

任务只有在以下项目齐全后才能标记“已完成（验收通过）”：

- 输入文件和版本明确；
- 各项任务按 §10.2 记录负责人、输入、假设、产出、复核、阻塞与下一步；
- 按步骤执行并留下记录；
- 交付物已保存；
- 假设、公式定义、数据来源和适用范围写清楚；
- 需要计算的结果已通过独立复核；纯文字任务则完成原文对照；
- 对应审稿意见有正文落点或有证据的“不纳入”理由；
- 回复信与实际修订稿一致。

**公共处理规则（适用于全部任务卡）：** 失败或未完成时标记“阻塞／进行中”，写清失败原因、受影响工作和可触发的下一步；条件性任务有证据证明不触发时才标“不适用”。所有计算脚本、参数文件和原始输出应在执行相应研究任务时保存。下面各卡仅列特有步骤，不重复这两条公共记录规则。

## 1. 总体执行顺序

按下面的依赖推进。**E1.1 是标量全范围扫描 S1.5 的必需输入，必须提前完成**；最终窗口需等待相关约束结案。“初步”和“最终”只是工作阶段，不代表当前已有研究结果。PMNS 决策与标量/实验资料整理可以并行；若选择扩展模型，则最终参数整合 E1.8 必须等待该扩展的 N3–N5 通过验收。

| 阶段 | 工作包 | 优先级 | 进入下一阶段的条件 |
|---|---|---|---|
| A | 原稿、审稿报告、公式、记号和引用基线 | P0 | 版本和关键位置可追溯；未知事项明确标记 |
| B | PMNS 结构核查、路线决策及必要的候选路线验证 | P0 | 若路线失败，返回 N1.3；路线未通过时不得宣布 PMNS 已解决 |
| C1 | S1.1 → E1.1 初始参数表 → S1.2–S1.5 → S1.6 初步窗口 | P0/P1 | 初始扫描输入先锁定；初步窗口标明未并入的限制 |
| D | E1.2–E1.7：VLL、动能混合、有限矢量耦合和条件性约束 | P1 | 各映射关系与实验比较有来源、有定义、有复核 |
| C2 | E1.8：合并最终标量窗口、EFT 匹配与 UV 可实现域 | P0 | 必需约束已合并；若采用 PMNS 扩展，N3–N5 已验收且新质量关系已计入 |
| E | 约束完整性筛查结案与 Minor Points | P1/P2 | 每条意见有明确修改或有依据的“不纳入”解释 |
| F | 正文、图表、回复信与终稿回归检查 | P0（提交前） | 所有原始评论单元均有最终落点，编号和结论一致 |

**停止／返回关卡：** N4 拟合失败、N5 实验冲突或 N3 模型不自洽 → 回到 N1.3 重新选择路线（另一候选、适用文献、或明确收窄模型主张），并记录审稿人可能仍不接受的风险。任何未通过的 P0 门槛均不可仅靠修改措辞自动结案；作者须评估是否具备提交条件。E1.8 的结果一旦扩大、缩小或重定义原始扫描区间，须启动 S1.5 等相应步骤的回归复核。

## 2. 阶段 A：锁定事实基线

### A0.1 冻结原始文件与确认稿件版本
- **目的：** 避免用错误版本解释审稿意见。
- **优先级：** P0。
- **输入：** `axial_vector_model_building-v6.pdf`、`dw13678_report_1_a.pdf`、投稿系统记录、提交邮件或版本归档。
- **依赖：** 无。
- **当前状态：** 未开始（开始执行后按第 0.2 节更新）。
- **操作步骤：**
  1. 将最终投稿稿和原始审稿报告保存为只读文件。
  2. 记录文件名、文件大小、日期／元数据；如环境允许，记录 SHA-256 校验值。
  3. 查找审稿人实际收到的稿件版本：优先查投稿系统上传记录，其次查提交邮件或团队版本归档。
  4. 将已确认的稿件版本与 v6 对照；若版本不同，单独保存差异，不覆盖任何原件。
  5. 若无法确认审稿人收到的版本，记录“无法确认”，不要推断边界差异来自误读、排版或规范化。
- **交付物：** `baseline_manifest.md`，包含原始文件、版本来源、文件路径和确认状态。
- **验收标准：** 所有后续公式与页码都能追溯到明确版本；未知版本问题有明确结案状态。

### A0.2 建立 38 项审稿意见覆盖表
- **目的：** 保证长段落中的每个要求都被独立回应。
- **优先级：** P0。
- **输入：** 原始审稿报告、`审稿意见逐条对照表-统一更新版-20261019.md`。
- **依赖：** A0.1。
- **当前状态：** 未开始（开始执行后按第 0.2 节更新）。
- **操作步骤：**
  1. 保留原始 Major 1–4、Minor 1–6 和 Recommendation 编号。
  2. 对含多项要求的句子拆分语义单元，例如“给范围”“量化混合”“比较约束”不能合并成一个笼统任务。
  3. 每个单元分配唯一标识：A、B、C、D、E、F、H 类，见第 9 节交叉表。
  4. 分开记录“审稿人原话”“工作归纳”“对应工作包”“最终证据位置”。
  5. 把 APV/PVES、额外衰变、LLP 等开放性筛查另列为条件性任务，不伪装成审稿人逐字提出的要求。
  6. 每次工作包更新后，只更新对应单元的状态和交付证据。

- **验收标准：** 38 项均映射至少一个任务 ID；任何“已回应”状态都附有正文或回复信落点。

## 3. 阶段 B：PMNS 与中微子质量

> 先完成最小模型的结构核查，再决定是否扩展。`σ` 与 `σ+3N_R` 是不同候选路线，任何一条都不能在未验证前写成“已经解决 PMNS”。

### N1.1 复核最小模型的荷选择规则与残余对称性
- **目的：** 用可复核的矩阵推导回答 Major 3.1 与 4.1。
- **优先级：** P0。
- **输入：** v6 场内容／电荷表、Weinberg 算符定义、带电轻子 Yukawa 项。
- **依赖：** A0.1、A0.3。
- **当前状态：** 未开始（开始执行后按第 0.2 节更新）。
- **操作步骤：**
  1. 抄录模型中所有相关轻子、Higgs 和 `S` 的规范荷。
  2. 根据 `S` 的荷与 VEV，推导破缺后是否存在残余离散对称性；把每一步变换写出。
  3. 将各味左手轻子按残余对称性分类。
  4. 逐项检查 Weinberg 算符 `L_i L_j H H` 的总荷，列出允许／禁止矩阵元素及其原因。
  5. 以同一荷表检查带电轻子 Yukawa 矩阵；不要未经推导就假定它必然对角。
  6. 写出中微子与带电轻子质量矩阵的分块形式，并解释哪些 PMNS 混合角会被结构限制。
  7. 将结构性结论与具体数值拟合区分开；不在本任务中声称已经完成拟合。
- **交付物：** 电荷选择规则表、允许算符表、质量矩阵和简短证明。
- **验收标准：** 每个矩阵零元素均有明确对称性依据；矩阵结论与文字描述一致。

### N1.2 检查仅加入右手中微子是否足够
- **目的：** 正面回应 Major 3.2，而非只给概括结论。
- **优先级：** P0。
- **输入：** N1.1 的荷表与允许算符表。
- **依赖：** N1.1。
- **当前状态：** 未开始（开始执行后按第 0.2 节更新）。
- **操作步骤：**
  1. 明确每个 `N_R` 的规范表示与 `U(1)'` 荷。
  2. 逐项列出允许的 Dirac 项 `L H N_R`，核对总荷。
  3. 逐项列出允许的 Majorana 质量项，包括可能的 `S`／`S†` 插入，并核对总荷。
  4. 写出 `m_D` 与 `M_R` 的矩阵结构。
  5. 将矩阵结构代入 seesaw 关系，检查是否仍保留与最小模型相同的分块。
  6. 正面核查审稿人关于第二、三代形成 vectorlike combinations 的说法：指出哪些表示／异常条件会强制或允许这种结构，避免泛泛回答。
  7. 若加入新费米子，逐项列出相关规范异常的计算清单和抵消条件。
- **交付物：** `m_D`、`M_R`、`M_ν` 矩阵及异常核对表。
- **验收标准：** “加入右手中微子是否解决问题”的结论由显式矩阵支持；异常条件有逐项记录。

### N1.3 作出 PMNS 论文路线决策
- **目的：** 决定论文是收窄主张，还是继续构造扩展模型。
- **优先级：** P0；需要作者确认。
- **输入：** N1.1、N1.2 的交付物；审稿人 Recommendation 原文。
- **依赖：** N1.1、N1.2。
- **当前状态：** 未开始（开始执行后按第 0.2 节更新）。
- **操作步骤：**
  1. 写出“保留最小模型并明确其 PMNS 限制”的路线，评估它能否充分回答审稿人关于模型一致性的关键质疑。
  2. 写出“加入奇电荷标量 `σ`”路线，明确它需要打破哪一条残余对称性限制。
  3. 将“`σ` 单独”与“`σ+3N_R`”作为两个独立候选方案，不合并成一个已确定方案。
  4. 对每条路线列出新增场、允许算符、质量矩阵、异常、标量势、参数数目、实验约束和计算工作量。
  5. 对文献路线逐篇核对荷指派和质量矩阵；不同模型的已知方案只能作为参考，不可直接宣称适用于当前模型。
  6. 为每条路线写出进入条件、成功判据和失败后的返回路径，记录哪些问题只能“限定模型适用范围”，哪些必须通过可行扩展解决。

### 10.3 结案规则

- 一项意见可以由多个任务共同回应；必须等所有必需任务验收后，才可关闭该意见。
- 一个任务也可以支持多项意见；回复信仍要保留每条原始意见的独立编号和明确回应。
- 条件性任务只有在触发条件成立后才执行；若不触发，须写明依据并标记“不适用（有依据）”。
- 不得以“已写入文档”“旧文件有数字”“计划已列出”作为物理工作完成的证据。
- 如果作者选择收窄论文范围而不扩展模型，必须明确关闭相应扩展分支，并说明这对审稿意见的回应充分性意味着什么。
