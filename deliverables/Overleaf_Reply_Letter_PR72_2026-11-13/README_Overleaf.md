# Overleaf import bundle — referee response letter

This archive is rebuilt from `main` at commit `3a3e8bb0eeb54a627cf2b2df315edf8badfe1dc8` in `lm846802297-bit/axial-vector-review-response`.

## Import and compile

1. Create a new blank Overleaf project and upload this ZIP as the project archive.
2. Keep `main.tex` at the project root.
3. Use pdfLaTeX and run the usual bibliography sequence: pdfLaTeX → BibTeX → pdfLaTeX → pdfLaTeX.
4. The archive includes both bibliography databases (`references.bib` and `Replies_to_Referee_3_stellar_references.bib`), the `JHEP.bst` style, and the reply-figure PDF at the exact path referenced by `main.tex`.
5. `reference_pdf/Replies_to_Referee_3_referee_facing_2026-11-04.pdf` is a visual reference copy; it is not an input to compilation.

## Integrity

`SHA256SUMS.txt` contains SHA-256 digests for every other file in this archive. Verify them after extraction.

This is the current `main` snapshot, not the older 2026-11-09 branch export. The older ZIP used an earlier TeX/PDF pair and omitted the current stellar-reference bibliography and included reply-figure PDF.
